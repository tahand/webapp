-----------------
Description
-----------------
Create a daily timeblocking/schedule to plan each day.
The daily planner will connect to a weather api to bring up to date weather status for the users location.
The daily planner data will store the data locally so that it can function offline.
An additional pomodoro timer will be available to configure a set time to countdown to.

[] Connect to weather api

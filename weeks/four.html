Creating the form

The basic form template has been created and includes a submit button with an action value of "" which means the form will submit back to itself.

I have focused on getting the content there initially and included a selection of different input types.

Submitting the form

The URL that it posts back to is the same page but with query string values of the form name and value that has been submitted.

http://127.0.0.1:5500/weeks/four.html ? fname = Andrew & surname = Chapman & fav_lang = HTML & vehicle1 = Bike

Updating my CSS file to style the form

The references sections includes hyperlinks that are too long for the viewport on mobile devices.
To correct this I set:
overflow-x: none;
overflow-wrap: break-word;
This prevents the text from overflowing outside the boundaries of the section element and allows it to wrap onto the lines below.

Javascript dynamic menu

I created a dynamicaly generated menu.

When the page loads a Javascript function is called that will use the document.getElementByTagName to find all the sections.

I then looped through the element object that this returned and built an array of values made up of the section id (key) and the innerText of the h2 element within this section.
The array is looped through and the key and values are use to build up li elements and add them to the ol element within the navigatoin menu.

The result is a navigation menu that dynamically builds up the menu items based on the sections of the web page and will reduce the chances of having broken links on the page or mismatched links to sections that could result from human error.
